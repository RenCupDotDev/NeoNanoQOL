# NeoNanoQOL

NeoNanoQOL is a set of quality of life plugins for the project [NeoNano](https://github.com/RenCupDotDev/NeoNano) by RenCupDotDev, it currently features:

- dirtree, a directory tree viewer
- terminal, a terminal emulator
- welcome, a welcome screen
- wordcount, a word counter
- lsp, a [Language Server Protocol](https://en.wikipedia.org/wiki/Language_Server_Protocol) interface 


All of these Plugins are from the project NeoNanoQOL, not NeoNano itself, complete stability is not guaranteed, All the plugins under NeoNanoQOL are licensed under the GPL v3.0 License
